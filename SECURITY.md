# Security policy

The supported version is the current main branch. Fixes are developed there first.

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/catuscio/rsquish/security/advisories/new).
Do not open a public issue with exploitable details or private images.

Include the affected revision, operating system, reproduction steps and a minimal
non-sensitive input where possible. Image parsing, native codec boundaries and
output-file handling are particularly useful areas to investigate.

This is a community-maintained project; no response-time SLA is promised. Please
coordinate public disclosure with the maintainer after a fix is available.
