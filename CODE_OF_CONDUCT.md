# Code of conduct

Help make rsquish a useful, welcoming project.

- Treat contributors and users with respect, regardless of background or experience.
- Discuss the code and evidence; avoid personal attacks, harassment or discrimination.
- Respect privacy. Never publish someone else's personal information or private files.
- Give constructive feedback and make room for different perspectives.

Maintainers may remove harmful content, close disruptive discussions or restrict
participation. Report misconduct through GitHub's reporting tools or contact the
maintainer privately through their GitHub profile. Reports will be handled with
care and shared only as needed to address the issue.
